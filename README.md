# 让 Grok Bot 成为你的 AI 队友

[![All Contributors](https://img.shields.io/github/all-contributors/yangwenmai/grok-bot-ai-teammate?color=ee8449&style=flat-square)](#contributors)

英文工作名：Make Grok Bot Your AI Teammate  
仓库：https://github.com/yangwenmai/grok-bot-ai-teammate

中文开源书：mdBook → GitHub Pages。主角绑死 Grok Bot；对照栏才出现 OpenClaw / Hermes / Workbuddy。

## 本地预览

```bash
# 安装 mdBook：https://github.com/rust-lang/mdBook/releases
mdbook serve --open
mdbook build   # 输出 book/
```

见 `src/SUMMARY.md`。中文七段在 `src/zh/`；英文同树空壳在 `src/en/`（V1 可空）。
