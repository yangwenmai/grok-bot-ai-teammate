## 关于本书

这是一本**自传式的社区历史**，记录了从 Go 夜读发起，到成为 Cursor Ambassador，再到 xAI / SpaceXAI Ambassador 的社区协作之路。

**这不是**一本 Grok Bot 使用手册或技术教程。

**这是**关于社区、朋友、活动与共创的故事集。

### 读者对象

- 想用社区方式办活动/做内容的人
- 对技术社区运营感兴趣的朋友
- 想了解从 Go → Cursor → xAI 路径的人

## 在线阅读

🔗 **GitHub Pages**（待部署）

本地阅读：

```bash
# 安装 mdBook
cargo install mdbook

# 或使用 Homebrew (macOS)
brew install mdbook

# 或下载预编译二进制
# https://github.com/rust-lang/mdBook/releases
```

```bash
# 本地服务
mdbook serve

# 访问 http://localhost:3000
```

构建：

```bash
mdbook build
# 输出到 book/ 目录
```
