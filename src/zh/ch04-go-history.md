# 第 4 章 · Go 语言发展史（社区视角）

## 本章定位

这**不是**一本 Go 语言教材。

这一章从**社区参与者的视角**，记录 Go 语言在中文社区的发展轨迹。

## Go 语言简史（公开事实）

- **2009** — Google 开源 Go 语言
- **2012** — Go 1.0 发布，承诺兼容性
- **2015–2018** — 中国公司（字节、腾讯、阿里等）大规模采用
- **2019–2022** — 泛型讨论与 Go 1.18 泛型落地
- **2023–2026** — 持续演进，社区成熟

## 中文社区的成长

Go 在中国的技术社区有自己的特点：

- **公司驱动** — 大厂技术团队的实践分享
- **翻译与本地化** — 中文文档、书籍、教程
- **线下 Meetup** — 北京、上海、深圳、杭州等城市
- **开源项目** — 国内开发者的 Go 开源贡献
