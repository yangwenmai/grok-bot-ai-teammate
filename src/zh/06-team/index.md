# 把一队 bot 跑顺

协作能跑之后，下一层是把重复的事收成制度。岗位、定时任务、做法说明、翻车怎么复盘。制度图的是一件很具体的事。你出门一天回来，队还在按你写过的规矩转。

## 岗位

每个 bot 一页纸就够。目标、不做的事、交付格式、找谁升级。形容词越少越好。

岗位页建议固定四个小标题。

1. 目标（交付物是什么）
2. 不做的事（禁区）
3. 交付格式（文件、表格、群消息长什么样）
4. 升级给谁（什么情况必须找你或找入口）

写完大声读一遍。若你自己都无法在一分钟内复述，bot 更会靠猜。岗位页改动后，在群里留一句变更说明，避免有人还按旧边界行事。

岗位页可以放在它能读到的地方。放哪里取决于你的习惯，文件、置顶消息、描述正文都可。关键是单一真相来源。同一 bot 有三份互相打架的岗位说明，等于没有岗位。

## 定时与触发

每天或每周固定交的活，不要靠你早上想起来。能定时就定时；有外部事件就用触发。

适合定时的例子。日报三行状态、每周链接简报、工作日傍晚看一次检查项。适合触发的例子。某公开页变更、某仓库检查变红、指定邮箱标签进来新信。

定时任务最怕空转。空转有两种。一种到点什么也没有，却回你已完成。一种出了事却在自说自话，不升级。写定时说明时，把无变化时回什么和异常时喊谁写进同一段。

触发任务最怕过敏。任何风吹草动都喊你，你会关掉通知。把触发条件写窄。例如只在检查失败且失败步骤包含某关键字时升级。先窄后宽，比先宽后烦更可持续。

## 做法说明（skill）

第二次还要做的流程，写成步骤和完成标准。下一个人（或下一个 bot）按文就能接着干。

好的 skill 通常具备四段。目的、步骤、完成标准、例外。例外尤其重要。例如找不到官方来源就停，不要用二手摘要冒充。没有例外的 skill，会在灰区里即兴发挥。

skill 不要写成小说。步骤用能勾选的句子。完成标准用能一眼判定的句子。写完让另一个 bot 或未来的你按文执行一次，卡住的地方就是要改的地方。

一份 skill 的长度宁短勿长。一页内能跑完的流程，不要写成五页背景介绍。背景放在岗位页或单独资料库。skill 只负责怎么做完这一次。

## 看得见

跑批历史如果看不细，就自己记账。今天派了什么、卡在哪、谁要拍板。可见性大于感觉团队很忙。

最低可见性可以很轻。

- 群里每条派活都有接收人与截止时间
- 完成时回帖贴上产物链接
- 你自己的工作日志每天三行，记录派了什么与谁在等你

可见性是为了复盘与升级，不为了制造汇报文化。没有人要看长篇感想。短、可点开、可核对，就够。

若你发现自己经常问它做完了没，先补可见性，再谈它够不够主动。主动却不可见，对你帮助有限。

## 翻车复盘

写清预期、实际、哪条边界没设、下次改哪一句描述或哪条流程。复盘进现场章，不进鸡汤。

复盘模板可以固定四行。

1. 预期
2. 实际
3. 漏设或写糊的边界
4. 已改动的描述 / skill / 定时说明（写清改了哪一句）

复盘的对象是制度文本，不只是模型脾气。同一类翻车第二次出现，优先怀疑你改得不够具体，再怀疑它没记住。

复盘写完，至少改动一处可执行文本。只写心情、不改句子，等于没复盘。

## 一周节奏示例

下面是一份可直接改的一周节奏。时间按你的时区自调。这里按工作日示意。

每天早上，入口管家交昨夜定时任务摘要（无变化也要明说），并列出今天等你拍板的事项，每条一行。每天傍晚，入口管家汇总各专人完成与未决；红灯项升级给你，附上能动手的链接或日志位置。每周一，研究员交一页带链接的主题简报，题目由你上周指定。每周三，写作者基于已拍板材料，交一版对内草稿或修订稿。每周五，你花十五分钟扫岗位页与 skill，改一句最糊的边界，并决定下周研究员题目，写进群里。

早交什么。早交昨夜摘要与今日待拍板清单，让你在处理自己的事之前，先知道队里卡点。谁升级。涉及对外发布、花钱、删文件、动线上，一律升级给你。专人之间口径冲突，升级给入口管家；入口仍判不清，再升级给你。升级时附带两份原文链接，避免你从零听故事。

节奏表不是绩效考核。它是默认心跳。某一周专题很重，可以暂停周报，改成专题节点。暂停时也要在群里写明，避免专人按旧定时空转。

## 工程向公开叙述作参考入口

工程向的一队人怎么跑，可参考 [lingxi 的公开叙述](https://x.com/lingxi/status/2094493172516966781)。数字以原帖为准，本书不转写未核验的细节，也不把该叙述扩成必须照做的编制表。你从中可借的是观察角度。岗位如何切开、何时才喊人合并、夜间自动活与白天验收如何衔接。借角度，不借神话。

读工程向叙述时，记得对照原则 4。能改回来的合并请求与改不回来的生产操作，升级门槛应不同。别人帖里的数字再好看，也替不了你账号里的边界句。

## 带队章的收束

跑顺的标志很朴素。你离开屏幕半天，回来仍能在群里看到谁在等你、谁已交卷、哪条红灯需要你本人出现。做不到这一点，先回到岗位与可见性，再谈扩编。
