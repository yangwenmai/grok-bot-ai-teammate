# 想一起写这本书

共创不是随便开 PR 塞感想。完整规则以仓库根目录 [CONTRIBUTING.md](../../../CONTRIBUTING.md) 为准。这里只讲读者向的三件事。

## 你可以贡献什么

- 现场案例（按模板，可核对）
- 推荐条目（必须有链接和为什么收）
- 勘误、过时价格、死链
- 译文（中文默认，英译后置）

## 你会被看见

项目用 [All Contributors](https://allcontributors.org/) 记录贡献类型。合入后按 CONTRIBUTING 更新名单，不要只改正文里的鸣谢句。

## 你不会被鼓励的

- 无出处的大而全教程改写
- 软广、邀请码、未标明的利益关系
- 把其它产品线叙事硬塞进 Grok Bot 主线

先读 CONTRIBUTING，再动模板。
