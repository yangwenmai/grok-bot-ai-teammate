# 第 5 章 · 分支：Go 夜聊 / Meetup / Go Con

## 为什么需要「分支」

Go 夜读是**线上直播**，持续且稳定。

但社区活动不能只有线上：

- **线下 Meetup** — 面对面交流
- **Go Con** — 更大规模的会议
- **Go 夜聊** — 更轻松的非正式讨论

这些**分支活动**扩展了夜读的影响力。

## Go 夜聊

**Go 夜聊**（Go Night Chat）是夜读的轻量版：

- 更随意的话题
- 不一定讲源码
- 更多互动与讨论
- 可能是语音/视频闲聊

**〔待 Mai 主笔〕**

- 夜聊是如何发起的
- 与夜读的区别
- 印象深刻的夜聊话题
- 参与者的反馈

## 线下 Meetup

从线上走到线下，是**信任的升级**。

### Meetup 的城市

- **深圳** — 主场
- **北京**
- **上海**
- **杭州**
- 其他城市（待补充）

### Meetup 的形式

- 技术分享（1–3 个话题）
- 圆桌讨论
- 自由交流
- 有时有赞助商支持场地

- 如何找场地、拉赞助
- 如何协调嘉宾与时间
- 线下与线上的不同感受

## Go Con（Go 大会）

**Go Con** 是更大规模的会议活动：

- 多轨分享
- 更多嘉宾
- 更多参与者
- 更正式的组织

**〔待 Mai 主笔〕**

- 是否参与过 Go Con 的组织或演讲
- Go Con 与 Meetup 的区别
- 对大规模会议的观察

## 分支活动的价值

这些分支活动为什么重要？

- **扩展连接** — 线上到线下，弱关系到强关系
- **积累经验** — 活动组织、嘉宾协调、现场把控
- **信任网络** — 见过面的人更容易深度合作
- **品牌积累** — "Mai 办的活动"成为一个信任标签

**〔待 Mai 主笔〕**

- 这些经验如何帮助后续 Cursor、xAI 活动
- 从 Go 社区学到的活动运营方法论

## 本章小结

Go 夜读的**分支**不是分散精力，而是**扩展影响力**。

这些经验，在后面的 Cursor Ambassador、xAI Ambassador 阶段，继续发挥作用。
