# 第 2 章 · Go 夜读怎么起来的

## 起点

**Go 夜读**（Go Night Reading）是一个技术直播项目，大约在 **2017–2018** 年间发起。

核心想法很简单：

> 晚上固定时间，读 Go 源码，讲技术话题，在线直播，欢迎所有人参与。

## 早期的挑战

做一个持续的技术直播，不是一件容易的事：

- **时间** — 每周固定时间，能坚持多久？
- **内容** — 源码讲解需要深入准备
- **嘉宾** — 如何邀请嘉宾分享？
- **观众** — 如何积累稳定的观众群？
- **工具** — 直播平台、录制、回放、字幕

**〔待 Mai 主笔〕**

- 早期的运营节奏

## 社区反响

Go 夜读逐渐在 Go 中文社区形成了自己的位置：

- GitHub 仓库积累 star
- 固定观众与参与者
- 嘉宾分享的丰富主题
- 形成录播回放资源库

很多技术直播做了几期就停了。Go 夜读为什么能持续？

**〔待 Mai 主笔〕**

Go 夜读是**起点**，也是**信任的积累**。

后面的很多事情 — 嘉宾网络、活动经验、社区连接 — 都从这里开始。
