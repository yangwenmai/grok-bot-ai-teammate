# 你有好几个 bot 的时候

一个人手不够用时，问题通常不在模型不够聪明，而在谁跟谁说话、活怎么交。

你可能已经从合集页或朋友那里搬来好几个模板。名字都好看，打开对话却像同时进了好几间会议室。这一章处理的就是这种噪音。

## 常见乱法

- 你自己同时跟七八个 bot 聊，上下文各说各的
- 两个 bot 职责重叠，互相抢活或互相踢皮球
- 交接只在一句你去问某某，没有可见记录

乱法还有变体。你在私聊里改了口径，群里的专人并不知道。或者入口 bot 把活派给了写作专人，研究专人又各自开工，最后你收到两份互相打架的结论。症状不同，根子相近。说话关系与边界没有写死。

识别乱法有一个省事办法。把昨天所有对话标题列出来，标出哪些是你主动开的。主动开的越多，入口越散。再标出哪些对话产出了可点开的文件或群记录。只有聊天没有产物的，优先怀疑无效忙碌。

## 更稳的做法

1. **少数入口。** 你日常只跟一两个管家说话。
2. **专人专事。** 写作、研究、工程分开，描述里写死边界。
3. **交接可见。** 派给谁、要什么结果、何时回来，写在群里或交接里。
4. **冲突时找人。** 两个 bot 口径不一致，回到你拍板，不要让它们私下扯皮。

社区里大量多 bot 经验，可从 [Eric 的长帖](https://x.com/ericzakariasson/status/2087259022172840124) 对照。本书只收能变成规矩的部分。帖里的具体招式会过时，入口、专人、可见交接这三件事更耐用。

更稳的做法不要求你一次建满编制。三人小队跑顺，价值高于十人编制空转。编制图好看，交不出可见结果，仍是噪音。

## 小型名单示例（入口管家 + 写作者 + 研究员）

下面是一份最小可跑的名单。名字可换，边界句式请留下。

**入口管家**

- 干什么。接收你的日常指令，拆成可派任务，交给写作或研究；汇总进度与要你拍板的事。
- 不干什么。不自己长篇写作，不深挖资料装成研究报告，不对外发帖。
- 交付。每次派活在群里写清接收人、结果定义、截止时间；每晚交三行状态。

**写作者**

- 干什么。按给定口径出提纲、初稿、按批注修改；保留事实与你的语气。
- 不干什么。不擅自改关键事实，不发明出处，不直接研究新议题冒充已核实材料。
- 交付。稿件文件链接与改动说明；涉及对外发送时停下来等你。

**研究员**

- 干什么。按题目收集公开资料，整理对比表，每条结论附链接。
- 不干什么。不写最终对外稿，不下采购或选型结论，不把未核实传闻写成事实。
- 交付。一页内简报，含链接与未决问题小节。

三人如何说话。你主要对入口管家说。管家把写一封对内说明派给写作者，把先核对三家公开页派给研究员。研究员交简报后，管家再请写作者基于简报起草。两份材料口径冲突时，管家停下来问你，不让两边继续互改。

边界怎么写才算写死。尽量写到可观察。不对外发帖，比注意措辞好检查。每条结论附链接，比认真调研好验收。形容词留给人看简历，岗位描述留给机器执行。

你可以把上面三段边界直接贴进描述，再按自己的领域改名词。先改禁区，再改交付格式。名字是否可爱，优先级最低。

## 什么时候才加第四个

前三个还没跑顺时，先别加。跑顺的最低标准可以很朴素。

- 你连续一周主要只跟入口说话
- 写作与研究没有互相抢同一类活
- 交接在群里找得到，不靠你事后回忆

需要工程专人、日程专人、客服专人时，仍沿用同一模板。先写干什么与不干什么，再决定它听谁的，最后才给更重的工具权限。

加第四个之前，也问一句。新岗位是新工作面，还是旧工作面的负载过重。负载过重，先优化 skill 与定时。新工作面，再开专人。用新人掩盖旧流程不清，队伍只会更吵。


## 入口管家当天可能收到的两句指令

示例一。「请研究员核对这三家公开定价页的功能差异，今天下午四点前交一页表，每格附链接。写作者先别动。」

示例二。「研究员简报已拍板。请写作者按简报起草对内说明，八百字内，今晚前交文件。不要发出去。」

两句指令里都有接收人、结果、时间、禁区。入口管家的价值，是把你的口语收成这种可派句式，再盯回执。你若自己天天写这种句式，入口也可以先由你兼任，等真的忙不过来再设专职管家。

## 练习

把你现有名单列出来。谁是入口，谁是专人，谁暂时不该出现在你的主对话里。

列完以后做一次删除练习。名字好听但两周没交过可见结果的，先停用或收进冷藏。冷藏用来降低噪音。真有活再唤醒，并重写边界。

若你愿意，把名单截成可核对的表，留给自己下一次复盘。表头可以很简单。名字、入口或专人、干什么、不干什么、最近一次可见交付。填不满的格子，就是下一次要补的描述。

第 6 章会把岗位、定时、skill、可见性与翻车复盘收成带队节奏。名单是骨架，节奏是血肉。
