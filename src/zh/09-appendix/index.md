# 附录 · 名词和链接

## 名词（少而清楚）

- **岗位 / 描述。** 这个 bot 负责什么、不负责什么。
- **skill。** 可编辑的做法说明。
- **定时 / 触发任务。** 到点或出事就自动跑起来的活。
- **交接。** 一只 bot 把活传给另一只，过程应看得见。
- **Cloud Agent。** Cursor 侧改仓库的云端编码代理；和 Grok Bot 聊天不是同一条额度。
