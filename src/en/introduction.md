# Introduction

Welcome to **My Community Friends** (《我和我的社区朋友们》).

This is an **autobiographical community history** documenting the journey from initiating Go Night Reading to becoming a Cursor Ambassador and then xAI / SpaceXAI Ambassador.

## About This Book

**This is NOT** a tool manual or technical tutorial.

**This is** a collection of stories about community, friends, events, and co-creation.

## Primary Language

The primary content is in **Chinese**. English content is provided as stubs for navigation.

For full content, please read the Chinese version.
